# 🛡️ Anti-XSS Shield

Браузерное расширение для продвинутой защиты от XSS-атак, мониторинга сетевых угроз и обеспечения безопасности пользовательских данных.

## 🚀 Главные особенности

* **Защита Cookies:** Предотвращает несанкционированное чтение кук сторонними скриптами и автоматически принудительно устанавливает критически важные флаги (`HttpOnly` и `Secure`).
* **Сетевой мониторинг:** Автоматически блокирует подозрительные домены и запросы (`fetch`, `xmlhttprequest`, `ping`) на уровне сети при обнаружении попыток атак.
* **Аудит зависимостей:** Сканирует подключенные на странице скрипты на предмет устаревших или потенциально уязвимых библиотек.
* **Система белых списков:** Позволяет гибко настраивать исключения для доверенных сайтов.
